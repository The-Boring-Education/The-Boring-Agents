# DSA Interview Questions - AI Agent Instructions

## MISSION STATEMENT

Create a comprehensive, language-agnostic Leetcode style DSA interview preparation sheet for Indian college students and working professionals. Focus on conceptual understanding over rote memorization with explanations suitable for a 10-year-old.

## TARGET AUDIENCE

-   College students preparing for placements
-   Beginners learning DSA concepts
-   Entry-level software engineering candidates
-   Working professionals refreshing DSA skills

## CONTENT REQUIREMENTS

### 1. EXPLANATION STYLE

-   Use real-world analogies and Indian context
-   Write in simple, jargon-free language
-   Include memory tricks and mnemonics
-   Focus on understanding over memorization
-   Provide step-by-step problem-solving approaches
-   Include common pitfalls and avoidance strategies

### 2. FORMATTING REQUIREMENTS

-   Use MDX format with proper styling and formatting
-   Make content simple, easy to understand, and readable
-   Include visual diagrams where helpful
-   Provide coding examples in Python, Java, and C++
-   Add time and space complexity analysis for each solution

### 3. QUESTION STRUCTURE

For each topic, provide:

1. **5 Interview Questions** (50:30:20 ratio for Easy:Medium:Hard)
2. **Step-by-step Problem-solving Approach** for each question
3. **Code Implementation** (multiple languages)
4. **Time/Space Complexity** (with explanation)
5. **Common Mistakes** (and how to avoid)
6. **Interview Tips** (specific to this problem)
